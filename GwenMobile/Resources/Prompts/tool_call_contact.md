Starts a phone call now to one person or business from the contacts; the app finds and dials the number. Use it whenever the user wants the phone to call somebody: "call Mum", "please call Family: Mother". Take whom, the relation and the number only from the user's own words, never from these examples. Never for a question about calls - that is answer_in_chat or search_web; never for calling a function or program, which is write_code; never to write a message or mail.

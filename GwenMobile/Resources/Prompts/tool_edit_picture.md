Changes a picture already in the chat or attached here and shows the result: new colour, bigger object, another background, anything sized or coloured. Never for removing colours only - that is make_monochrome. Set monochrome true only when the change also makes it black and white. It never reads words out of a picture - answering what a picture says is answer_in_chat; for answer and change, call answer_in_chat first and this tool second.

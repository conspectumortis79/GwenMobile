Deletes the whole conversation history on the device: every saved conversation and the current one, leaving an empty chat. Use it whenever the user asks to delete, clear, wipe or reset the history or chats - also with the configured phrase. It is never a request to delete only the running conversation: every chat goes. Never for one message, a reminder, an appointment, a shopping item, a file, a picture or a stored fact ({{memory_tool}}).

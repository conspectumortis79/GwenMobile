Lists the closest places of one kind to where the user is now: the nearest supermarket, pharmacy, station, ATM, shop or chain. For one named destination use route_to_place. It knows no opening hours or prices: a message that wants a place and such a fact together is this call with search_web the second, and a wish that wants only the fact is search_web, never this call. If the user names how many places to show, pass that number as count; otherwise leave count out.

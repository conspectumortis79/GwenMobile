Reports the cheapest real offer for one watched product from the fetched sources, calling report_price once. It must match the watched configuration exactly - chip, memory and storage. A source with another memory, storage or chip is not an offer; when no source proves the configuration, do not call. Use only prices a SOURCE prints: never shipping, monthly rate, accessory, used device or another model. price uses a dot decimal, currency the printed ISO code, shop the shop's name, source the SOURCE line number, product the configuration as printed. Never invent a price, shop or address.

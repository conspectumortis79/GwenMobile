Generates a new picture from words, also when the subject really exists. Use it for every wish to produce a picture, any verb, any language; a real person, actor or place does not make it a photo lookup. It draws diagrams too: a chart, graph, flowchart, mind map or table the user wants to see, even with numbers. Never for code, a program, a game or a web page - that is write_code, even with a file type such as HTML. Never to look up existing photos - that is find_pictures. Never for a video; that is create_video.

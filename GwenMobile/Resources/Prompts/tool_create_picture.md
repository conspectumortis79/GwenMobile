Generates a new picture from words, also when the subject really exists. Use it for every wish to produce a picture, any verb, any language; a real person, actor or place does not make it a photo lookup. It draws diagrams too, even with numbers. Never for code or a file - that is write_code, even with a file type. Never to look up existing photos - that is find_pictures. Never for a video; that is create_video.

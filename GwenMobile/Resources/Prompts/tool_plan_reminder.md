Keeps and checks reminders and to-do lists: create, update, complete, delete and list reminders, shopping list items, tasks and place triggers on arrival or leaving. Use it for every such wish. Read a separated prefix at the end of the message together with the verb at its start; the item between them is that verb's object. When the newest message names an item already on a list and adds no new content, never create a second copy; use complete when it marks the item done, otherwise update or delete. A short command about one item with no reminder verb and no word for adding, creating, buying or putting is not create; it acts on an existing item, complete when it means finishing or checking off, otherwise update or delete. Never create an item when the user marks an existing item as finished, done, ticked off or checked off; that is complete with the item as find, also with a short, colloquial or separated verb. A place trigger is only a when or where condition. A person, object or task after the reminder verb is the title, never a location, list or find. Take values only from the user's words and never translate the title. Several different things to buy or put on a list are several calls, one per thing; a named place and a named list belong to every call they cover; never put a place into list, notes or title, and never put a list into location. A verb for finishing, checking off or ticking off an existing item is complete with that item as find; create only when the user introduces a new item. A list question is list with its list. A delete uses find. A name the user introduces as the reminder's name is the title; content the user introduces as the reminder's content is notes; neither is a list. Never for an explicit timer ({{timer_tool}}), an appointment with start and end ({{calendar_tool}}), the time or date ({{clock_tool}}), or buying something.
